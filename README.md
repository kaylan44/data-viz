# MarketDeck

A dark, trading-terminal-style data-visualization SPA built in Vue 3. Portfolio project demonstrating component architecture, reactive data patterns, and data visualization techniques.

> **Simulated data for demonstration purposes only.** No real market prices are used.

## Overview

Four pages, each with live-updating simulated data:

| Page | Description |
|------|-------------|
| **Equities** | Magnificent 7 dashboard — price table, sparklines, line chart, tick log |
| **Oil Markets** | Brent / WTI / Dubai crude |
| **Markets Overview** | Global indices, rates, FX, commodities, crypto — grouped view |
| **World Map** | Clickable SVG map with country detail panel (population, GDP, currencies, languages) |

## Architecture

```
src/
  app/            Router, layout shell (AppShell, SidebarNav, TopBar)
  components/
    ui/           Generic primitives: Panel, DataTable, SegmentedControl, …
    data/         Finance-aware: Sparkline, FlashValue, PriceChange, TickLog
    charts/       LineChartPanel (ECharts, tree-shaken)
    map/          WorldMap (d3-geo + topojson), CountryPanel, MapControls
  composables/    useLiveQuotes, useHistory, useCountries, useFlashOnChange
  data/
    engine/       Seeded PRNG, GBM / Ornstein-Uhlenbeck generators, tick engine
    providers/    MarketDataProvider interface — swap mock → real in one line
    catalog/      Instrument definitions per group
    countries/    Static country snapshot + GDP snapshot (committed JSON)
  stores/         Pinia: market quotes (shallowReactive Map)
  pages/          Thin orchestrators — no business logic
  types/          Instrument, Quote, Point, TimeRange, ChartMode
```

Key patterns:
- **Config-driven dashboards**: `MarketDashboard` receives a config object; Equities, Oil, Overview are configs only.
- **Deterministic history**: seeded mulberry32 PRNG + GBM/OU processes anchored to `todayMidnightUtc()`.
- **Correlated moves**: Mag 7 and oil instruments share a common market factor.
- **One-line provider swap**: change `src/data/providers/mockProvider.ts` to plug in a real data source.

## Stack

| Layer | Package |
|-------|---------|
| Framework | Vue 3 + `<script setup lang="ts">` |
| Build | Vite 8, TypeScript strict |
| Router | vue-router 4 (lazy routes) |
| State | Pinia |
| Styling | Tailwind CSS v4 (`@tailwindcss/vite`) |
| Charts | ECharts + vue-echarts (tree-shaken) |
| Map | d3-geo, d3-zoom, topojson-client, world-atlas |
| Icons | @lucide/vue |
| Fonts | Inter + JetBrains Mono (self-hosted via @fontsource) |

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

### Useful scripts

```bash
npm run build        # Production build
npm run type-check   # TypeScript check
npm run lint         # ESLint

# One-time data scripts (outputs already committed):
node scripts/snapshot-gdp.mjs              # Refresh World Bank GDP data
node scripts/build-countries-snapshot.mjs  # Rebuild country list from static data
```

## Simulated data notice

All prices, rates, and market data displayed in this application are **simulated for demonstration purposes only**. They are generated by a seeded pseudo-random number generator using geometric Brownian motion and Ornstein-Uhlenbeck processes. No real market data is used.
